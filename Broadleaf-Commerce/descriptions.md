# Broadleaf Commerce - File Descriptions

## 1. AdminCatalogService.java

This file defines the AdminCatalogService interface for administrative catalog operations. It declares functionality for generating product SKUs and cloning products. It provides an abstraction for catalog-related administrative operations.

## 2. AdminCatalogServiceImpl.java

This file provides the implementation of AdminCatalogService. It contains the actual business logic for administrative catalog operations such as generating SKUs and cloning products. It demonstrates separation between a service interface and its implementation.

## 3. AdminModuleRegistration.java

This file registers the Broadleaf Admin module with the application. It implements BroadleafModuleRegistration and provides the module name "Admin". It is part of the module configuration and registration mechanism.

## 4. OfferQualifyingCriteriaValidator.java

This file implements validation logic for offer qualifying criteria. It extends the validation framework provided by Broadleaf and checks whether qualifying criteria are properly configured for specific offer templates. It demonstrates component-based validation and separation of validation responsibilities.
